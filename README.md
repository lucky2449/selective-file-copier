# 파일모아

사진 번호나 파일명 목록으로 필요한 파일을 찾아 복사·다운로드하는 웹 도구입니다. JPG로 받은 셀렉 목록에서 같은 이름의 RAW를 찾거나, RAW와 JPG를 함께 저장할 수 있습니다.

**[파일모아 사용하기](https://lucky2449.github.io/selective-file-copier/)**

[사용 방법](#사용-방법) · [검색 규칙](#검색-규칙) · [저장 방식](#저장-방식) · [원본 보호](#원본-보호) · [개발 안내](DEVELOPMENT.md) · [로그 서버 운영](server/operation-logs/README.md)

## 주요 기능

- 원본 폴더와 하위 폴더에서 사진 번호·파일명·경로로 검색
- TXT 목록 불러오기, 선택한 파일에서 이름 가져오기
- 체크한 확장자만 저장하며 같은 폴더·같은 이름의 RAW/JPG 함께 선택
- 중복 후보 직접 확인, 결과 개별·전체 선택
- 결과 하단에서 저장 예정 파일 수·용량·확장자별 개수 확인
- 지정 폴더 복사, 파일별 다운로드, 최대 약 4GB ZIP 다운로드

## 사용 방법

1. **원본 폴더 선택**으로 사진이 있는 폴더를 엽니다.
2. **찾을 목록**에 번호·파일명을 입력합니다. TXT나 참고 파일에서 가져와도 됩니다.
3. **복사할 파일 확장자**에서 JPG·CR3·NEF 등 필요한 형식을 체크합니다. 처음에는 모두 미선택입니다.
4. **파일 찾기**를 누르고 결과를 확인합니다. 후보 확인이 필요한 항목은 직접 선택합니다.
5. 저장할 항목을 체크하고 아래 방식 중 하나로 저장합니다.

| 원하는 방식 | 사용 방법 | 저장 결과 |
| --- | --- | --- |
| 파일별 다운로드 | 저장 폴더를 지정하지 않고 **선택 파일 다운로드** | 브라우저 다운로드 설정에 따라 개별 파일 저장 |
| 폴더 직접 복사 | **저장 폴더 선택** 후 **선택 파일 복사** | 선택한 폴더 안에 새 결과 폴더 생성 |
| ZIP 다운로드 | **ZIP 다운로드** | 복사용 저장 폴더와 별개로 브라우저 다운로드 요청 |

첫 저장 시 안내를 확인해야 작업이 시작됩니다. 다운로드 완료 여부는 브라우저의 다운로드 목록에서 확인하세요.

## 검색 규칙

**저장할 형식은 입력한 파일명의 확장자가 아니라 체크한 확장자로 결정됩니다.**

| 입력 예시 | 검색 결과 |
| --- | --- |
| `323` | 끝 숫자가 같은 `DSC00323.JPG` 등을 검색. 선행 0은 무시 |
| `IMG_0001` | 확장자를 제외한 이름이 같은 파일 검색 |
| `IMG_0001.JPG` + CR3 체크 | JPG가 없어도 `IMG_0001.CR3` 검색 |
| `IMG_0001.JPG` + JPG·CR3 체크 | 같은 폴더의 JPG와 CR3를 함께 저장 |
| `day1/IMG_0001.JPG` | `day1` 안에서 검색. 다른 폴더의 동명 파일로 대체하지 않음 |

- 파일명의 대소문자는 구분하지 않습니다. 번호 `23`은 `DSC00323`과 일치하지 않습니다.
- ‘모든 파일’은 발견한 확장자를 전부 선택합니다. 개별 확장자를 모두 체크한 경우와 결과가 같습니다.
- 다른 폴더의 동명 파일은 자동으로 묶지 않습니다. 후보가 여러 개면 경로를 보고 선택하세요.
- 조건을 변경하면 다시 검색해야 합니다. 원본 폴더 재선택·초기화 시 확장자 선택도 초기화됩니다.
- Windows 절대 경로는 선택한 원본 폴더와 연결할 수 있을 때만 검색합니다. 선택하지 않은 폴더에는 접근하지 않습니다.

목록은 줄바꿈·쉼표·세미콜론으로 구분합니다. 숫자 목록은 공백이나 `/`로도 나눌 수 있습니다. 공백·구분자가 포함된 파일명은 큰따옴표로 감싸세요.

```text
323, 2134
IMG_0001.JPG
day1/DSC00323.JPG
"photo, summer.jpg"
```

TXT는 UTF-8을 먼저 적용하고 읽기에 실패하면 EUC-KR로 해석합니다. TXT는 5MB 이하, 입력은 한 번에 최대 20,000개 항목을 지원합니다.

**제조사별 사진 번호 후보 포함**을 켜면 `P1000001.RW2` 같은 이름에서 추가 번호 후보를 찾습니다. 추정 후보는 하나여도 직접 확인해야 합니다. [지원 형식과 예외](CAMERA_NUMBER_RULES.md)를 참고하세요.

## 저장 방식

### 폴더 직접 복사

- 폴더 쓰기 API를 지원하는 데스크톱 브라우저에서 사용할 수 있습니다.
- 기기 현지 시간 기준 `YYYYMMDD_HHmmss` 폴더를 만듭니다. 예: `20261019_143025`.
- 같은 결과 폴더명이 있으면 `_2`, `_3` 등을 붙여 새 폴더를 만듭니다.
- 원본의 하위 폴더 구조는 재현하지 않고 선택한 파일을 한곳에 모읍니다. 파일명 충돌은 이름 뒤에 번호를 붙여 구분합니다.
- 파일 내용은 복사하지만 수정 시각 등 운영체제 메타데이터까지 보존하지는 않습니다.

브라우저가 시스템·다운로드 폴더 등의 직접 접근을 차단하면 다른 폴더를 선택하거나 일반 다운로드를 사용하세요. 복사 실패 시 저장 방식이 자동으로 바뀌지는 않습니다.

### 일반 다운로드와 ZIP

일반 다운로드는 브라우저의 저장 위치·저장 전 확인 설정을 따릅니다. 여러 파일 다운로드 허용이 필요할 수 있습니다. 앱은 기존 다운로드 폴더를 검사할 수 없으며, 기존 파일과의 충돌 처리는 브라우저가 결정합니다.

ZIP은 **무압축**으로 생성합니다. 브라우저 전용 임시 저장소(OPFS)에 순차 기록한 뒤 다운로드하며, ZIP 전체를 JavaScript 배열에 모으지 않습니다.

| 항목 | 제한 |
| --- | --- |
| OPFS 지원 환경 | ZIP 부가 정보 포함 4,294,967,295바이트 이하(4GiB 미만) |
| OPFS 미지원 환경 | 메모리 방식으로 512MiB 이하 |
| ZIP 파일 수 | 최대 65,535개. ZIP64 미지원 |

임시본과 다운로드 사본을 위한 여유 공간이 필요합니다. 공간 부족 시 작업을 중단합니다. [ZIP 처리·임시 공간 상세](ZIP_STORAGE.md)

## 원본 보호

원본 파일은 읽기 용도로 사용하며 원본 수정·삭제·이동 기능을 제공하지 않습니다.

- 직접 복사는 새 결과 폴더에 저장하고, 쓰기 전·완료 직전에 대상 충돌과 변경 여부를 검사합니다.
- 같은 사이트·브라우저 프로필의 여러 탭이 직접 복사를 동시에 실행하면 순서대로 처리합니다.
- 복사 실패·취소 후 남은 결과 파일이나 폴더는 자동 삭제하지 않습니다.
- `Zone.Identifier` 부가 파일은 검색·저장에서 제외하며 원본에서 삭제하지 않습니다.

일반 원본 폴더 선택은 실제 폴더 핸들을 제공하지 않으므로 원본과 저장 폴더의 동일·포함 관계를 완전히 확인할 수 없습니다. 다른 프로그램이나 브라우저의 동시 접근도 차단하지 못합니다. 중요한 파일은 별도 백업하고, 저장 결과를 확인한 뒤 원본을 정리하세요.

다운로드 취소는 추가 요청을 중단합니다. 이미 요청한 다운로드는 브라우저에서 별도로 취소해야 합니다.

## 통계와 작업 기록

파일 검색·복사·ZIP 생성은 브라우저에서 처리합니다. **파일 내용·파일명·폴더 경로·입력 목록은 서버로 전송하지 않습니다.**

| 구분 | 용도와 처리 범위 |
| --- | --- |
| GA4 | 방문·기능 사용 통계. 쿠키 식별자와 기기·브라우저 정보 처리 |
| 서버 작업 기록 | 접속·저장 시작/종료, 파일 수·용량·오류 코드·버전 등. Cloudflare에 90일 기준 보관 후 순차 정리 |
| 진단 기록 다운로드 | 현재 페이지의 최근 단계 기록을 JSON으로 내려받기. 파일 정보 제외, 새로고침 시 초기화 |

외부 통계·작업 기록은 공식 GitHub Pages에서 활성화됩니다. 통신 실패가 파일 작업을 중단하지는 않습니다. 일반 다운로드·ZIP의 기록은 실제 저장 완료가 아닌 다운로드 요청을 의미합니다.

[통계 설정과 집계 기준](DEVELOPMENT.md#통계-설정-ga4) · [서버 수집 범위·보관·조회](server/operation-logs/README.md)

## 로컬 실행과 개발

저장소를 내려받은 **프로젝트 폴더에서** 실행하세요. Python 3가 필요하며 웹 실행을 위한 npm 설치·빌드는 필요 없습니다.

```powershell
python -m http.server 8080 --directory docs --bind 127.0.0.1
```

[http://127.0.0.1:8080/](http://127.0.0.1:8080/)을 엽니다. 404가 나오면 현재 폴더에 `docs/index.html`이 있는지 확인하세요.
